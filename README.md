# Database Solutions

This repository contains database-related solutions, classwork, homework, and exam-oriented material. It focuses on SQL queries, database design concepts, and practical problem-solving using relational databases.

## Overview

The repository serves as a reference for studying and revising core database concepts. It includes written SQL queries, explanations, and theory-based answers commonly covered in database modules and assessments.

## Repository Structure

The repository consists mainly of text-based files containing queries and explanations.

/
├── classwork files
├── homework files
├── exam preparation files
├── reference documents
└── README.md

Each file contains SQL queries, database concepts, or theory-based answers related to database topics.

## Getting Started

### Clone the repository

git clone https://github.com/rishhabhsingh/DB_SDAC.git
